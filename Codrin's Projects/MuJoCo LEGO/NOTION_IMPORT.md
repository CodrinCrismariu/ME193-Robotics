# Put the presentation in Notion

1. Create a blank Notion page and import `PROJECT_NOTION.md` using Markdown import, or paste its Markdown into the page.
2. The presentation uses absolute GitHub URLs, so its images and links also work outside the repository.
3. For inline video players, paste each raw MP4 link from the presentation into a separate Notion video/embed block. Markdown links alone may remain clickable links. If an external URL will not embed, upload the corresponding MP4 from `media/`.
4. Check the CAD drawing, training plot, and videos in the imported page. The Markdown file itself does not create a native Notion page.

The presentation has no fabricated answers to unspecified course reflection questions. It includes project-specific engineering lessons and limitations instead.
